# Inter font assets

These files are unmodified desktop TTFs from the official Inter 4.1 release:

- `Inter-Regular.ttf` — weight 400;
- `Inter-Medium.ttf` — weight 500;
- `Inter-SemiBold.ttf` — weight 600.

Source: <https://github.com/rsms/inter/releases/tag/v4.1>.
